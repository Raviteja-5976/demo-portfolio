# Portfolio Neo-Brutalist Design System

> Based on the OpenRiverStack design language and expanded into a production-ready portfolio system.

# Philosophy

Build a portfolio that feels like a collectible magazine rather than a corporate website.

Core principles:

- Neo Brutalism
- Editorial layouts
- Paper textures
- Physical shadows
- Playful interactions
- Smooth motion
- High accessibility
- Fast performance

# Tech Stack

# GSAP

Use GSAP for:

- Page intro
- Hero entrance
- Section reveal
- Timeline draw
- Counter animations
- Text splitting
- Cursor background
- Magnetic buttons
- Project hover
- Card stacking
- Modal animations
- Loader
- ScrollTrigger
- Mouse parallax

Recommended plugins:

- ScrollTrigger
- SplitText
- Flip

# Framer Motion

Use Framer Motion for:

- Route transitions
- Page transitions
- Shared layout animations
- Hover animations
- Card expansion
- Mobile navigation
- Drag interactions
- Stagger children
- Presence animations

Avoid mixing GSAP and Framer on the same property simultaneously.
